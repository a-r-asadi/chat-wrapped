How to export a chat

  1. Open Telegram Desktop (the phone apps can't export).
  2. Open the chat, click ⋮ in the top-right, then Export chat history.
  3. Untick photos, videos and files (they aren't needed, and the export is faster without them).
  4. Set Format to Machine-readable JSON and click Export.
  5. Drop the result.json file from the export folder above.

A full-account export (Settings → Advanced → Export Telegram data, JSON) works too. You'll be asked which chat to look at.
